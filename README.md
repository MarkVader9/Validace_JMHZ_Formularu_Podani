# Validace_JMHZ_Formularu_Podani
Tento repozitář obsahuje XML soubory v Main Branch pro validaci vůči zdrojové dokumentaci která je obsažená v podsložkách s konkrétními názvy složek jednotlivých pilířů legislativy JMHZ. Dále tento repozitář slouží pro kontrolu, opravy a úpravy jako rozšiřování a/nebo zefektivňování .vb souborů Exportních Formatterů mzdového softwaru SALARY.
